# 06_ARCHIVES — Documents archivés

Contient les versions obsolètes, anciennes routines, documents fusionnés.

**Important** : Ce dossier ne doit **jamais** être chargé automatiquement.

## Structure

```
06_ARCHIVES/
├── chartes-anciennes/
│   ├── [REMPLACÉE PAR V8] Charte V7.md
│   ├── [REMPLACÉE PAR V7] Charte V6.md
│   └── ...
├── routines-obsoletes/
│   ├── veille-hebdo-3-magazines/ (remplacée par /veille)
│   └── audit-hebdo-sites/ (remplacée par /audit)
└── README.md
```

## Raison d'être

- Historique (comprendre l'évolution)
- Récupération (si besoin de relire une ancienne approche)
- Ne pas encombrer le système actif

## Accès

Les archives ne doivent être consultées que si :
1. Recherche historique
2. Question spécifique ("comment c'était avant ?")
3. Récupération d'un document perdu

## Suppression

Aucun document archivé ne doit jamais être supprimé.

Archive = conservation permanente.
