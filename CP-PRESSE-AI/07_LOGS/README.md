# 07_LOGS — Journalisation et traçabilité

Contient les liens vers les journaux d'exécution.

## Journal d'exécution — CP Presse

**Localisation** : Google Drive / 00-Pilotage / Journal d'exécution — CP Presse

Traçabilité complète de chaque article :
- Date
- Site
- Sujet
- ID WordPress
- Statut
- Nils approuvé
- Date publication

Ce journal n'est **pas** une mémoire de prompt ou un résumé contextuel.

C'est uniquement un **registre d'exécution**.

## Historique par session

**Localisation** : `Projet Nils/JOURNAL.md`

Historique des sessions, décisions, blocages.

À mettre à jour à chaque session.

## Format

- Markdown (lisible par n'importe quel agent)
- Structuré (dates, sites, IDs)
- Pas d'interprétations, juste les faits

## Indépendance

Les journaux doivent rester accessibles sans dépendre d'aucun outil (Claude, Google Docs, etc.).

Markdown pur = indépendance totale.
