# 05_WORKFLOWS — Processus éditoriaux

Contient les étapes standardisées pour les tâches courantes.

## Workflows

### creation-article.md
Étapes complètes pour créer un nouvel article.

De l'idée à la publication en brouillon.

### validation.md
Checklist avant publication (SEO, images, contenu, metadata).

Ce que Nils doit vérifier avant de publier.

### publication.md
Étapes pour publier un brouillon WordPress.

Du brouillon à "publié" + journalisation.

## Utilisation

Consulter le workflow correspondant avant d'entreprendre une action.

Pas de dépendance à un outil spécifique.
Format : Markdown simple.
