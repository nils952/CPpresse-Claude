# Workflow — Valider avant publication

Checklist avant de cliquer "Publier" sur WordPress.

## Yoast SEO

- [ ] Focuskw défini et présent dans H1
- [ ] Focuskw dans corps (100 premiers mots)
- [ ] Focuskw dans métadesc
- [ ] Titre SEO : 50-60 caractères
- [ ] Métadesc : 150-160 caractères
- [ ] Score Yoast : 🟢 VERT (jamais rouge)
- [ ] Lisibilité : orange ou vert (jamais rouge)

## Contenu

- [ ] Pas de 3 phrases consécutives commençant par le même mot
- [ ] Pas de "très" (à moins d'exception explicite)
- [ ] Pas d'emojis
- [ ] Pas de tirets longs (—)
- [ ] Minimum 2 liens internes
- [ ] Minimum 600 mots (idéal 800-1200)

## Images

- [ ] Image Une présente (1600×900px min)
- [ ] Alt texte renseigné
- [ ] Titre image renseigné
- [ ] Crédit/légende si applicable

## Metadata WordPress

- [ ] Catégorie correcte (voir Table de référencement)
- [ ] Minimum 2 tags
- [ ] Auteur : claude-editorial
- [ ] Slug propre (pas de `-2`, `-3`)

## Relecture

- [ ] Titre lu à haute voix (fluidité)
- [ ] Chapô (engagement)
- [ ] Conclusion (satisfaction lecteur)
- [ ] Pas d'erreur typo évidentes

## Tâches (si applicable)

- [ ] Vérifier source/lien vers article original (si reprise)
- [ ] Vérifier prix/chiffres actuels (si article pratique)
- [ ] Vérifier dates événement (si article actu)

## Statut = Brouillon

**Avant publication** : rester en brouillon tant que :
- Yoast pas vert
- Image absente
- Nils pas approuvé

## Après validation ✅

L'article est prêt pour publication manuelle.

Voir `/publication` pour les étapes finales.
